# User Stories

## Group Management
- As a user, I want to create a group so that I can manage shared expenses
- As a user, I want to join a group so that I can participate in group expenses

## Expense Management
- As a user, I want to add an expense so that I can track spending
- As a user, I want to split bills so that costs are shared fairly

## Debt Tracking
- As a user, I want to see who owes whom so that I can manage debts
- As a user, I want to confirm payments so that debts are updated correctly
